# Software

This folder contains the Arduino sketches used while developing and testing the DIY SpeedCoach.

The code is being built up in stages, starting with testing the individual GPS and TFT display before combining them.

## Current progress

- GPS communication tested with the L76K module
- TFT display tested and basic SpeedCoach layout created
- GPS and display successfully working together
- GPS fix and satellite count shown on the display
- Basic distance tracking added

The latest walking test successfully detected movement, but GPS drift still caused the distance to increase while stationary. This will be improved in the next version.
