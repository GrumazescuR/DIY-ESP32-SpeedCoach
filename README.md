# DIY ESP32 SpeedCoach
> An open source rowing computer built from scratch using an ESP32, GPS and IMU

## Overview 

This project documents the design and development of my own rowing SpeedCoach using an ESP32, GPS and IMU. My goal is to create a working prototype which is capable of displaying speed, 500m split, average split, elapsed time, stroke rate and distance per stroke while developing my embedded systems skills.

## Project Objectives 

The initial prototype aims to provide the following:

- Live boat speed
- 500 m split
- Average split
- Elapsed time
- Distance travelled
- Stroke rate
- Distance per stroke

Future versions may also include the following:

- GPS route logging
- Session recording
- Bluetooth connectivity
- Heart rate integration
- Data export

## Development Philosophy

Rather than assembling the entire system at once, each hardware component will be tested individually before being integrated into the complete device. This approach simplifies debugging, improves reliability and provides a better understanding of how each subsystem contributes to the final design.
