# DIY-ESP32-SpeedCoach
This project documents my attempt to design and build my own rowing SpeedCoach using an ESP32, GPS and IMU. My goal is to create a working prototype which is capable of displaying speed, 500m split, average split, elapsed time, stroke rate and distance per stroke while developing my embedded systems skills.

# Project Objectives 

The initial prototype aims to provide the following:

- Live boat speed
- 500 m split
- Average split
- Elapsed time
- Distance travelled
- Stroke rate
- Distance per stroke

Future versions may also include the following:

- GPS route logging
- Session recording
- Bluetooth connectivity
- Heart rate integration
- Data export
